# Wi-Fi and Network

## Office Wi-Fi networks
- CORP-SECURE: for company laptops; connects automatically using your device certificate.
- CORP-GUEST: for visitors and personal phones; the daily password is available at reception and expires at midnight.

## Cannot connect to CORP-SECURE
1. Turn Wi-Fi off and on again, then select CORP-SECURE and click "Forget", then reconnect.
2. Make sure the laptop date and time are correct; a wrong clock breaks certificate authentication.
3. Connect via a network cable and run "gpupdate /force" in a command prompt to refresh the certificate.
4. If it still fails, raise a ticket under "Network > Wi-Fi" with your laptop asset tag.

# Software Installation and Hardware Requests

## Installing approved software
- Approved software is installed from the Software Center (Windows) or Self Service (macOS) without admin rights.
- Software not listed there requires a request in the IT portal under "Software > New Software Request". Security review takes 3 to 5 business days.
- Users do not have local administrator rights. Do not install unlicensed or pirated software.

## Hardware requests
- New laptops, monitors, keyboards and headsets are requested through the IT portal under "Hardware Request" and need manager approval.
- Standard laptop refresh cycle is 4 years.
- Damaged or lost laptops must be reported within 24 hours. Lost or stolen devices must also be reported to Security on extension 3000 so the device can be remotely wiped.

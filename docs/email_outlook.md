# Email and Outlook

## Outlook does not open or hangs on "Loading Profile"
1. Close Outlook completely and check Task Manager that no OUTLOOK.EXE process is running.
2. Start Outlook in safe mode: press Win+R, type `outlook.exe /safe`, press Enter.
3. If safe mode works, disable add-ins under File > Options > Add-ins > COM Add-ins.
4. If it still fails, repair the profile under Control Panel > Mail > Show Profiles.

## Mailbox full
- Standard mailbox quota is 50 GB.
- Empty the Deleted Items folder and enable the Online Archive for older mail.
- Additional quota requires manager approval through an IT portal request.

## Shared mailbox access
- Shared mailbox access is requested by the mailbox owner through the IT portal, category "Email > Shared Mailbox".
- Access appears in Outlook automatically within 2 hours of approval.
